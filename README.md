## 📂 Proyectos insignia

### [`Auditor-de-Seguridad`](https://github.com/loerayamil-star/Auditor-de-Seguridad)
Herramienta en Python que audita repositorios mediante detección heurística de secretos, Bandit, flake8 y reportes estructurados. Representa mi enfoque de **AppSec y seguridad integrada al desarrollo**.

### [`mini-SOC`](https://github.com/loerayamil-star/mini-SOC)
Proyecto de homelab para desplegar monitoreo y detección con Wazuh sobre Proxmox. Representa mi exploración de **SOC, observabilidad e infraestructura bajo restricciones reales**.

### [`orquestador-con-seguridad`](https://github.com/loerayamil-star/orquestador-con-seguridad)
Diseño de un asistente multiagente con permisos por canal, acciones clasificadas por riesgo, confirmaciones y auditoría. Representa mi exploración de **AI Security y seguridad por diseño**.

### [`sistema-bancario-poo`](https://github.com/loerayamil-star/sistema-bancario-poo)
Sistema bancario educativo en Python con POO, excepciones personalizadas, persistencia JSON y pruebas con pytest. Representa mi base de **ingeniería de software y modelado de reglas de negocio**.

## ⚙️ Cómo trabajo

Utilizo IA como parte de un proceso de ingeniería asistida que yo diseño, reviso y valido.

En la mayoría de mis proyectos, Claude actúa como tutor: yo escribo el código y la IA me ayuda a revisar la lógica, identificar casos límite y razonar sobre posibles errores.

En `mini-SOC` y `orquestador-con-seguridad`, también la utilicé como asistente de implementación directa. En esos casos, yo definí la arquitectura, el alcance, el modelo de amenazas, los límites de privilegios, el sizing y los criterios de aceptación. Documento las decisiones y limitaciones de cada proyecto.
